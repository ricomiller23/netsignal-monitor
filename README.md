# NETSIGNAL
Internet Outage, Connectivity & Network-Integrity Monitor (Volume II, Part 18)

## Core Invariant Principles
1. **Anomaly vs Outage vs Shutdown**: An anomaly is a single-source deviation; an outage is corroborated disruption; a shutdown is an attributed restriction assertion.
2. **Cause Is an Attributed Assertion**: Causes are stored in a separate table with verbatim quotes and citations; never inferred from drop percentages.
3. **Ongoing Duration Unknown**: Active disruptions never display speculative durations.
4. **Modelled Users Not Summed**: Modelled population impacts are not aggregated across disparate events.
